# บัญชีความครอบคลุมข้อมูลศูนย์ข้อมูลเกษตรระดับประเทศ (National Agriculture Data Center Coverage Inventory)

รันคำสั่งตรวจสอบ:
```powershell
.\.venv\Scripts\python.exe scripts/audit_coverage_inventory.py
```
ผลลัพธ์โครงสร้าง JSON บันทึกที่ `data/local/probes/coverage-inventory.json`

ตามเป้าหมายของ [ศูนย์รวมข้อมูลเกษตรระดับประเทศ](national-agriculture-data-center.md) และข้อกำหนด [HANDOFF.md](../HANDOFF.md) ระบบรวบรวมและตรวจสอบความครอบคลุมข้อมูล (Coverage Inventory) ที่ระดับ `source × area × period × metric` โดยอ้างอิงจาก manifest และ staging records ที่ตรวจพิสูจน์ค่าแฮช SHA-256 แล้วในเครื่อง ไม่สร้างหรืออนุมานการกระจายตัวเลขระดับประเทศหรือจุดพิกัดลงสู่รูปแปลงจังหวัดโดยไม่มีข้อมูลรองรับ

## 4. สถานะสิทธิ์และความปลอดภัย (Data Governance)

1. ทุกทรัพยากร (100%) ในบัญชีความครอบคลุมถูกระบุ `license_status = "pending"` ตาม [ทะเบียนสิทธิ์](source-license-register.md)
2. ชุดข้อมูลที่มีข้อมูลระบุตัวตน บุคคล หรือข้อมูลติดต่อ (เช่น ทะเบียนผู้บริหาร, ที่ตั้งวิสาหกิจ, ข้อมูลคำขอเพิ่มสินค้า) ถูกจำกัดให้อยู่ในชั้นภายใน (`internal only`) เท่านั้น
3. ห้ามส่งออกข้อมูลดิบหรือแถวที่มีสถานะ pending สู่ชุดข้อมูลสาธารณะ (Public Export) จนกว่าจะได้รับอนุญาตเป็นลายลักษณ์อักษร
