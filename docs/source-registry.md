# ทะเบียนแหล่งข้อมูลและรหัสจังหวัด

ชุดเริ่มต้นมีแหล่งข้อมูล 15 ราย ครอบคลุมพืช ราคา อากาศ น้ำ ดิน ดาวเทียม ภัยพิบัติ ปศุสัตว์และประมง ตาม [สเปก v1.4](../Thailand_Agricultural_Decision_Intelligence_Hub_Thailand_First_v1.4_2026.md) ส่วน 48 แต่ละแหล่งยังต้องตรวจ resource, schema, ปีข้อมูล, key, quota และสิทธิ์เผยแพร่เป็นรายชุด ก่อนนำข้อมูลออกสาธารณะ

ไฟล์ [sources.json](../config/sources.json) ใช้รหัสโดเมน AG01 ถึง AG20 ตามสเปก ส่วน 1.1 และแยก `runtime_verified`, `license_status`, `auth_status` ออกจากกัน การตอบ HTTP สำเร็จยืนยันได้เฉพาะการเข้าถึงในขณะทดสอบ ไม่ยืนยันสิทธิ์เผยแพร่หรือความครอบคลุมรายจังหวัด ผลตรวจจริงอยู่ใน probe manifests ไม่เปลี่ยนทะเบียนต้นฉบับให้กลายเป็นการรับรองทุก resource

## รหัสจังหวัด

[provinces.csv](../config/provinces.csv) มี 77 รหัสตามระบบกรมการปกครอง รวมกรุงเทพมหานคร `10` และบึงกาฬ `38` ตรวจชื่อและรหัสกับ [มาตรฐานข้อมูลจังหวัดของกระทรวงพาณิชย์](https://std.moc.go.th/std/group/28) ซึ่งอ้างกรมการปกครอง รุ่น 1 แก้ไข 16 กรกฎาคม 2562 และตรวจเทียบ [DDPM Geocode](https://capportal.apiddpm.com/SeverityInformation) วันที่ 22 ตุลาคม 2569

การตรวจนี้รับรองเฉพาะการถอดชื่อและรหัสจากแหล่งอ้างอิง ไม่ได้รับรองว่าเป็นรุ่นเขตการปกครองล่าสุดทุกระดับ `geom_version` ว่างเพราะยังไม่มีขอบเขต polygon ที่ผ่านการตรวจ อำเภอ ตำบล พิกัดศูนย์กลาง และการถ่วงน้ำหนักพื้นที่ยังไม่ถูกสร้างขึ้น

ข้อมูลจุดหรือสถานีใช้รหัสจังหวัดได้เพื่อจัดหมวดตำแหน่ง แต่ต้องคง `spatial_support` เดิม ไม่แสดงเป็นค่าสถิติทั้งจังหวัด ข้อมูลระดับประเทศไม่กระจายเป็นค่า 77 จังหวัด

## สิทธิ์และสถานะ coverage

ทะเบียนตั้งต้น `license_status=pending` ทุกแหล่ง ไม่มี token หรือข้อมูลเกษตรกรรายบุคคล [เงื่อนไข Open-Meteo](https://open-meteo.com/en/terms) ระบุ attribution ข้อมูล CC BY 4.0 และจำกัด API ฟรีสำหรับงานไม่เชิงพาณิชย์ จึงต้องตรวจรูปแบบใช้งานก่อนกำหนดสิทธิ์ส่งออก

ใช้ `UNVERIFIED` เมื่อยังไม่ตรวจการเผยแพร่จริง ห้ามใช้ `NOT_PUBLISHED` แทนคำว่า “ยังไม่ดึง” และห้ามเปลี่ยนค่าที่ขาดเป็น 0 สถานะอื่นคือ `AVAILABLE`, `NOT_PUBLISHED`, `NOT_APPLICABLE`, `PIPELINE_ERROR` โดยต้องเก็บเหตุผลตามหลักฐาน

ข้อมูลเกษตรต่างประเทศและการเปรียบเทียบทั่วโลกอยู่ใน `deferred_sources` สถานะ `Deferred` ผู้ให้บริการต่างประเทศใช้ได้ในระยะแรกเฉพาะข้อมูลอากาศ/ดาวเทียมของพื้นที่ไทยตามสเปก

## Data contracts

[data_contracts](../data_contracts/) เก็บ JSON Schema Draft 2020-12 สำหรับ geography, observation, coverage, price, production, forecast และ risk signal ตารางแยกตาม grain และต้องมี provenance ค่าที่ขาดเป็น `null` กฎ runtime ใน `quality.py` ตรวจเพิ่มเรื่องเวลา ตัวเลข finite รหัสแหล่งข้อมูล และชนิดราคา สคีมาอย่างเดียวไม่ยืนยันความถูกต้องทางวิทยาศาสตร์หรือสิทธิ์เผยแพร่

`observation` และ `coverage` ตรงกับรูปแบบรับเข้า/ส่งออกปัจจุบัน `price`, `production` และ `forecast` เป็นสัญญา fact table สำหรับระยะเพิ่มข้อมูล ไม่ได้หมายความว่ามีข้อมูลจริงหรือ connector พร้อมแล้ว ผลทดลองจาก forecast CLI ต้องแปลงเข้า fact contract พร้อม provenance ก่อนใช้งานจริง `actual_count=0` หมายถึงยังนำเข้าแถวที่ผ่านเกณฑ์ไม่ได้ ส่วนจำนวนที่คาดว่าควรมีและจำนวนที่ขาดยังเป็น `null` จนกว่าจะตรวจต้นทาง
