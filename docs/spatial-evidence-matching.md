# หลักฐานปัญหาเชิงพื้นที่และสถานะมาตรการ

สถานะ 23 ต.ค. 2569: บัตรพื้นที่ 77 จังหวัดมีหลักฐานจากรายงาน DOAE ที่ตรวจได้รวม 115 รายการ แต่ **สถานะมาตรการทั้ง 77 จังหวัดเป็น `UNVERIFIED`** เพราะทะเบียนโครงการยังไม่มีพื้นที่เป้าหมายระดับโครงการที่ตรวจแล้ว ข้อสรุปเดิมว่า `UNADDRESSED_GAP` 46 จังหวัด, `COVERED` 12 จังหวัด และ `REDUNDANT` 3 จังหวัดถูกถอน ไม่ใช้เป็นผลการวางแผนหรือวัดผลงาน

การไม่มีรายงานภัยในชุด DOAE ที่อ่าน ไม่ได้แปลว่าไม่มีปัญหาในจังหวัดนั้น และการไม่มีโครงการในทะเบียนที่ยังไม่ครบ ไม่ได้แปลว่าไม่มีหน่วยงานดูแล ข้อมูลภัยเป็นรายงานจาก resource/ช่วงเวลาที่มีเท่านั้น ไม่ใช่สถานการณ์ปัจจุบันทุกพื้นที่ ช่วงเวลาสังเกตของสองไฟล์ภัยที่ใช้ใน audit ยังระบุไม่ได้จากคอลัมน์ต้นทาง จึงเก็บ `observed_period=null`

รายการหลักฐานเก็บ resource ID, ชนิดภัย, ค่าและหน่วยไร่ ผลรวมที่แสดงเป็นระดับจังหวัดจากแถวพื้นที่ต้นทาง แยกภัยน้ำท่วม ภัยแล้ง และพื้นที่เฝ้าระวังขาดแคลนน้ำ ไม่รวมเป็นคะแนนความเสี่ยงหรือรับรองความเสียหายรายปี ข้อมูลจำลองถูกกันออกตามตัวตรวจเดิม สิทธิ์ทุกชุดยัง `pending`; feed สาธารณะไม่ส่งบัตรเหล่านี้

ขั้นต่อไปคือยืนยันความหมาย/ช่วงเวลาของแต่ละ resource, ตรวจการซ้ำและการรวมยอด แล้วเชื่อมทะเบียนโครงการที่มีพื้นที่เป้าหมายและเวลาที่ตรวจได้ ก่อนจำแนกว่าพื้นที่ได้รับการดูแล ซ้ำซ้อน หรือยังเป็นช่องว่าง

ตรวจซ้ำในเครื่อง:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/audit_spatial_evidence.py
```
