# M5: Explorer แสดง metadata ของข้อมูลตัวเลข

เพิ่มใน `web/components/data-explorer.tsx`: เมื่อโหลดแถวข้อมูลแล้ว หน้าแสดงระดับข้อมูลของ resource ที่เลือก, วันที่ข้อมูลล่าสุดจาก `meta.dataAsOf` และเวลาที่ดึงจากต้นทางจาก `meta.sourceRetrievedAt` ตามเวลาไทย. `meta.retrievedAt` ยังคงเป็นเวลาที่ API ตอบกลับ. ช่องที่ไม่มีค่าจะแสดง “ยังไม่ระบุ”; ไม่อนุมานจากเวลาแก้ไข metadata. ถ้า completeness เป็น `partial` จะแสดงคำเตือนจาก API. แถว `grid` แสดงเป็นเซลล์กริดและพิกัดเมื่อมี longitude/latitude ที่เป็นตัวเลขทั้งคู่ โดยไม่แสดงรหัส cell เสมือนเป็นจังหวัด.

ตารางเดิมแสดงแหล่งอ้างอิงและหน่วยอยู่แล้ว. ตรวจโค้ดและการใช้ formatter; ยังไม่ได้ตรวจหน้าใน browser. รัน `npm.cmd run typecheck` จาก `web/` หลังรวมงาน API ที่กำลังเปลี่ยนอยู่.
