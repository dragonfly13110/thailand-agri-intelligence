## 2. เกณฑ์การเปิดสิทธิ์การรวมยอด (Rollup Eligibility Gate)

จะเปิดสิทธิ์ `rollup_eligible = True` เฉพาะเมื่อผ่านเกณฑ์ครบทุกข้อ:

1. **Spatial Agreement:** รหัสและชื่อพื้นที่ตรงกับ DOPA snapshot 2023 หรือได้รับการแก้ปัญหาด้วยกฎ Temporal Crosswalk ข้างต้น
2. **Temporal Validity:** ช่วงเวลาของข้อมูล (`source_period_year`) สอดคล้องกับช่วงเวลาที่มีผลบังคับใช้ (`valid_from` และ `valid_to`) ของรหัสนั้น
3. **Additive Metrics Only:** ตัวชี้วัดต้องเป็นปริมาณที่บวกสะสมได้เท่านั้น เช่น พื้นที่เพาะปลูก (ไร่), พื้นที่เก็บเกี่ยว (ไร่), ผลผลิต (กก./ตัน), จำนวนครัวเรือน
4. **Non-Subtotal Filter:** ต้องไม่ใช่แถวที่เป็นผลรวมย่อย (Subtotal) หรือยอดรวมประเทศ/ภาค เพื่อป้องกันการนับซ้ำ (Double Counting)
5. **ห้ามรวมตัวชี้วัดอัตราส่วน/ราคา:** ตัวชี้วัดผลผลิตต่อไร่ (Yield), ราคา (Price), สัดส่วนเปอร์เซ็นต์ หรือดัชนี NDVI จะถูกบล็อกเป็น `rollup_eligible = False` เสมอ และต้องคำนวณแบบถ่วงน้ำหนัก (Weighted Average) เมื่อต้องการสรุปผลระดับจังหวัด
