รันคำสั่งตรวจสอบ:
```powershell
.\.venv\Scripts\python.exe scripts/reconcile_plan_actual.py
```
ผลลัพธ์โครงสร้าง JSON บันทึกที่ `data/local/probes/plan-actual-reconciliation.json`

ตามข้อกำหนดใน [HANDOFF.md](../HANDOFF.md) และ [national-agriculture-data-center.md](../SYSTEM_DESIGN.md) กำหนดให้การเปรียบเทียบผลสำเร็จของโครงการ/การเพาะปลูก ต้องเปรียบเทียบเฉพาะพืช พื้นที่ ฤดูกาล รอบเพาะปลูก และหน่วยนับที่ตรงกันเท่านั้น **ห้ามคำนวณอัตราความสำเร็จระดับประเทศโดยนำยอดผลลัพธ์รวมมาหารด้วยยอดแผนรวม เมื่อพื้นที่ที่รายงานผลไม่ตรงกับพื้นที่ที่วางแผน**

## 1. ผลการตรวจสอบความแนบนัยของข้อมูลฤดูกาล 2569

### 1.1 ฤดูฝน 2569 (Rainy Season 2569)
- **แผนการเพาะปลูก (`rainy-season-crop-plan`):** 477 แถว (ระดับตำบล) ครอบคลุม **3 จังหวัด** ได้แก่:
  - `20`: ชลบุรี
  - `40`: ขอนแก่น
  - `94`: ปัตตานี
- **ผลการเพาะปลูกที่รายงาน (`rainy-season-crop-result`):** 3 แถว (ระดับจังหวัด) รายงานเฉพาะ **1 จังหวัด** ได้แก่:
  - `10`: กรุงเทพมหานคร (มูลค่าพืชไร่ 200 ไร่, ข้าวนาปีเกี่ยวแล้ว 200 ไร่, ข้าวนาปีต่อเนื่อง 200 ไร่)
- **ผลการกระทบยอด:**
  - $\{20, 40, 94\} \cap \{10\} = \emptyset$ (ไม่มีจังหวัดที่ตรงกันเลย)
  - **สถานะ:** `INCOMPARABLE` (เปรียบเทียบไม่ได้)
  - **เหตุผลวินิจฉัย:** ไม่สามารถประเมินผลสำเร็จของแผนฤดูฝน 2569 ได้ เนื่องจากพื้นที่รายงานผลไม่ตรงกับพื้นที่เป้าหมายในแผน ระบบปฏิเสธการหารตัวเลขข้ามจังหวัดเพื่อป้องกันการรายงานผลเท็จ

### 1.2 ฤดูแล้ง 2569 (Dry Season 2569)
- **แผนการเพาะปลูก (`plan_dryplant` ปี 2569):** 599 แถว ครอบคลุม **4 จังหวัด** ได้แก่:
  - `20`: ชลบุรี
  - `46`: กาฬสินธุ์
  - `81`: กระบี่
  - `90`: สงขลา
- **ผลการเพาะปลูกที่รายงาน (`dry-season-crop-result`):** 10 แถว ครอบคลุม **5 จังหวัด** ได้แก่:
  - `10`: กรุงเทพมหานคร
  - `12`: นนทบุรี
  - `13`: ปทุมธานี
  - `14`: พระนครศรีอยุธยา
  - `41`: อุดรธานี
- **ผลการกระทบยอด:**
  - $\{20, 46, 81, 90\} \cap \{10, 12, 13, 14, 41\} = \emptyset$ (ไม่มีจังหวัดที่ตรงกันเลย)
  - **สถานะ:** `INCOMPARABLE` (เปรียบเทียบไม่ได้)

## 2. กฎธรรมาภิบาลข้อมูลการเปรียบเทียบ (Governance Guardrails)

1. **Spatial Intersection Gate:** ต้องจับคู่ระดับพื้นที่เดียวกัน (รายจังหวัด หรือ รายตำบล) หากจังหวัดเป้าหมายของแผนกับผลไม่ตัดกัน จะแสดงสถานะ `INCOMPARABLE` ทันที
2. **Missing as Null:** จังหวัดที่มีแผนแต่ยังไม่มีรายงานผล จะคงค่าผลลัพธ์เป็น `null` เสมอ ห้ามตีความว่ามีผลลัพธ์เป็น 0 ไร่
3. **Additive Quantity Only:** คำนวณอัตราส่วนเฉพาะตัวชี้วัดพื้นที่ (ไร่) หรือน้ำหนักผลผลิต (ตัน) ห้ามนำราคาหรือผลผลิตเฉลี่ยมาหารตรง
4. **Diagnostic Transparency:** ส่งออกข้อความวินิจฉัยกำกับทุกครั้งเพื่อแสดงให้ผู้บริหารและนักวิเคราะห์ทราบเหตุผลที่แท้จริง
