# รูปแบบที่พบและข้อจำกัดนิยามข้อมูลพืชล้มลุก กรมส่งเสริมการเกษตร (รต.01)

## 1. วัตถุประสงค์และขอบเขต

เอกสารนี้สรุปรูปแบบที่นับพบในชุดข้อมูล 50,103 แถว (CKAN Resource ID `f9ab6055-6364-4f78-812e-15989e300979`) เทียบกับคำอธิบายระบบ รต.01 และคู่มือที่เข้าถึงได้ ใช้บอกสิ่งที่พบในไฟล์และตั้งสมมติฐานสำหรับตรวจต่อ **ยังยืนยันไม่ได้ว่า `เดือน` และ `รอบการปลูก` ใน CSV ส่งออกนี้ตรงกับช่องหรือกติกาใดในระบบต้นทาง** จึงยังห้ามใช้ผลตรวจนี้อนุมัติการรวมยอดหรือจับคู่แผนเทียบผล

## 2. โครงสร้างระบบ รต.01 และโมเดลสมดุลอ่างน้ำ (Stock & Flow Mass-Balance)

คู่มือ รต.01 อธิบายความต่างระหว่างพื้นที่ยืนต้นต้นงวด พื้นที่ปลูกใหม่ และพื้นที่เก็บเกี่ยวระหว่างเดือน โดยมีแนวคิด stock/flow ดังนี้:

$$\text{area\_last\_month} = \text{area\_first\_month} + \text{area\_new} + \text{area\_sprout} + \text{area\_fix} - \text{area\_blooey} - \text{area\_harvest}$$

1. **`area_first_month` (เนื้อที่ยืนต้นต้นเดือน):** เป็น stock ยกยอดจากงวดก่อนตามคู่มือ
2. **`area_new` (เนื้อที่ปลูกใหม่):** เป็น flow ที่คู่มือแยกจากพื้นที่ยืนต้น
3. **`area_harvest` (เนื้อที่เก็บเกี่ยว):** เป็น Flow การเก็บเกี่ยวที่เกิดขึ้นในเดือนนั้น
4. คู่มือเชื่อมการเก็บเกี่ยวกับผลผลิตและราคาเฉลี่ยในแบบรายงานนั้น

**ขอบเขต:** คำอธิบายของแบบรายงานไม่พิสูจน์ว่า CSV ของ CKAN เป็นแถวจากแบบฟอร์มดังกล่าวโดยตรง หรือว่าฟิลด์ที่ export มีความหมาย/สูตรเดียวกันทุกประการ

## 3. ผลการวิเคราะห์ข้อมูลจริงเชิงประจักษ์ (50,103 แถว)

จากการวิเคราะห์ฐานข้อมูล Staged ทั้ง 50,103 แถว พบข้อเท็จจริงสำคัญดังนี้:

### 3.1 การกระจายตัวระดับตำบล (Grain Distribution)
- จาก 50,103 แถว มีคู่กุญแจ `(จังหวัด, อำเภอ, ตำบล, กลุ่มพืช, ชนิดพืช, พันธุ์พืช, ปี)` รวม **50,101 กุญแจ**
- มีเพียง **2 กุญแจ** ที่มีข้อมูลมากกว่า 1 แถวในรอบปี (พิจิตร-บางมูลนาก-วังสำโรง-ข้าวนาปรัง 2 แถว, และนราธิวาส-บาเจาะ-บาเระใต้-ตะไคร้ 2 แถว)
- **ข้อสรุป:** ชุดที่ export นี้ **ไม่ใช่ Panel รายเดือน 12 เดือนของทุกตำบล** ข้อเท็จจริงนี้บอกจำนวนแถวที่พบเท่านั้น ยังบอกไม่ได้ว่าแต่ละแถวเป็นรอบสรุป งวดรายงาน จุดสูงสุดของฤดู หรือผลตามการตั้งค่า export

### 3.2 การกระจายของรหัส `planting_round` ที่สังเกตได้
ในไฟล์นี้พบความสัมพันธ์ระหว่างรหัสกับชนิดพืช แต่ยังไม่มีพจนานุกรมหรือคำยืนยันจากเจ้าของข้อมูลว่ารหัสแปลว่าอย่างไร:
1. **รหัส `0` (38,478 แถว):** พบพืชไร่และผักหลายชนิด เช่น มันสำปะหลังโรงงาน 3,125, อ้อยโรงงาน 2,262 และตะไคร้ 1,719 แถว
2. **รหัส `1` (7,941 แถว):** พบข้าวนาปี 6,102 และข้าวโพดเลี้ยงสัตว์ฤดูฝน 1,545 แถว
3. **รหัส `2` (3,684 แถว):** พบข้าวนาปรัง 2,590 และข้าวโพดเลี้ยงสัตว์ฤดูแล้ง 403 แถว

รูปแบบนี้เป็น **ความสัมพันธ์ในข้อมูล** ไม่ใช่การถอดรหัสนิยามทางการ ไม่ควรเรียกรหัสเหล่านี้ว่ารอบหลัก/รอบแล้งในตัวกรองหรือสูตรคำนวณจนกว่าจะได้ mapping ของ export จากเจ้าของชุดข้อมูล

### 3.3 การกระจายของ `month` ที่สังเกตได้
จำนวนแถวของข้าวนาปีพบมากในเดือน พ.ค.–ส.ค., ข้าวนาปรังใน พ.ย.–ม.ค. และพืชรอบสั้นจำนวนมากใน ม.ค. คู่มือ รต.01 อธิบายการรายงานรายเดือน แต่การกระจายนี้ยัง **ไม่ยืนยันว่าเดือนใน CSV คือเดือนรายงาน เดือนปลูก เดือนเก็บเกี่ยว หรือเดือนที่เลือกส่งออก**:
- **ข้าวนาปี (6,102 แถว):** รายงานหนาแน่นช่วงฤดูเพาะปลูก พ.ค. (2,775), มิ.ย. (1,561), ก.ค. (859), ส.ค. (446)
- **ข้าวนาปรัง (2,590 แถว):** รายงานหนาแน่นช่วง พ.ย. (908), ธ.ค. (931), ม.ค. (726)
- **พืชผัก/พืชรอบสั้น (รอบ 0):** รายงานหนาแน่นในเดือน ม.ค. (23,422 แถว) ซึ่งเป็นงวดสรุปหรือเปิดฤดูกาลเพาะปลูกต้นปี

### 3.4 ค่าพื้นที่ปลูกและเก็บเกี่ยวที่พบในกรณีนครปฐม
จากการตรวจละเอียดในกรณีตัวอย่างข้าวนครปฐมปี 2566 (97 แถว):
- 87 แถว มีเนื้อที่ปลูกเท่ากับเนื้อที่เก็บเกี่ยวพอดี
- 10 แถว มีเนื้อที่ปลูกต่างจากเนื้อที่เก็บเกี่ยว:
  - กรณี ต.ตลาดจินดา อ.สามพราน (เดือน 10): ปลูก 14 ไร่, เนื้อที่เก็บเกี่ยวและผลผลิตเป็น `null` (กำลังเพาะปลูก ยังไม่ถึงเวลาเก็บเกี่ยว)
  - กรณี ต.บัวปากท่า อ.บางเลน (เดือน 6): ปลูก 10,367 ไร่, **เก็บเกี่ยว 17,439 ไร่** (เนื้อที่เก็บเกี่ยวมากกว่าเนื้อที่ปลูกใหม่)
  - กรณี ต.ห้วยพลู อ.นครชัยศรี (เดือน 5): ปลูก 1,710 ไร่, **เก็บเกี่ยว 1,860 ไร่**
- การที่พื้นที่เก็บเกี่ยวมากกว่าพื้นที่ปลูกในแถวเดียวกัน **สอดคล้องกับ** ความต่างระหว่าง stock ต้นงวดกับพื้นที่ปลูกใหม่ที่อธิบายในคู่มือ แต่ยังพิสูจน์กลไกของแถว export นี้ไม่ได้ เพราะไม่มี field/event lineage ที่จับคู่กลับแบบรายแถว ส่วนสาเหตุของค่า null ก็ยังยืนยันไม่ได้จาก CSV

## 4. ผลต่อเกณฑ์การประมวลผลและการรวมยอด (Aggregation Guardrails)

1. **ยังไม่รวมข้ามเดือนหรือรอบ:** รอเจ้าของข้อมูลยืนยันความหมาย field, กฎรายงาน/ส่งออก, รุ่นแก้ไขและ subtotal ก่อน
2. **รักษา missing เป็น null:** ค่า null หมายถึงไม่มีค่าในแถวนี้ ยังสรุปสาเหตุว่าไม่ถึงเวลาเก็บเกี่ยวหรือเสียหายไม่ได้
3. **นำเสนอตามค่าต้นทาง:** แสดงเลขเดือนและรหัสรอบตามเดิมพร้อมระบุว่านิยามยังไม่ยืนยัน ไม่เปลี่ยนรหัสเป็นชื่อฤดูกาลเอง

## 5. สถานะ mapping ต้นทาง

การตรวจ resource metadata รอบ 24 ต.ค. 2569 พบว่าไม่มี DataStore dictionary/schema สำหรับ resource นี้ และ metadata ไม่ระบุ calculation method, standard หรือ version; ระบบต้นทางต้องเข้าสู่ระบบและไม่มีการใช้บัญชีหรือ credentials ในการตรวจครั้งนั้น รายงาน `data/local/probes/source-mapping-review-2026-10-24.json` จึงคงสถานะ `exact_export_mapping_unresolved` ไว้ก่อน จนกว่าจะได้คำอธิบายจากเจ้าของข้อมูลหรือหลักฐาน query/export ที่ผูกฟิลด์กับแบบรายงานได้ตรง
