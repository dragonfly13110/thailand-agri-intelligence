# เป้าหมายการทำงาน: ศูนย์รวมข้อมูลเกษตรระดับประเทศ

สถานะที่ตรวจแล้วและรายการงานค้างอยู่ใน [HANDOFF.md](../HANDOFF.md) เว็บต้องรับข้อมูลจาก API หรือ connector ที่ดึงจากแหล่งต้นทาง ไม่ใช้ local raw/staging/DuckDB เป็นแหล่ง runtime ของหน้าเว็บ เอกสารนี้กำหนดเป้าหมายและลำดับ ไม่ได้ยืนยันว่าข้อมูลทุกจังหวัดหรือทุกหน่วยงานพร้อมใช้แล้ว

**คำสั่งล่าสุด 24 ต.ค. 2569:** ส่งมอบผ่านเว็บ Next.js + TypeScript, หยุด Power BI และให้ข้อมูลที่เว็บแสดงมาจาก API/สคริปต์เชื่อมแหล่งต้นทาง ดู [ADR-001](decisions/0001-nextjs-web-delivery.md), [ADR-002](decisions/0002-source-backed-web-data.md) และ [แผนเว็บ](../tasks/plan.md) การเปลี่ยนช่องทางไม่ลดเกณฑ์คุณภาพ สิทธิ์ หรือความครอบคลุมข้อมูล

ศูนย์นี้ช่วยกรมส่งเสริมการเกษตรและหน่วยงานอื่นตอบร่วมกันว่า **พื้นที่ใดมีปัญหาอะไร มีหลักฐานใด โครงการใดทำอยู่แล้ว ควรทำอะไรต่อ และผลเป็นอย่างไร** ครอบคลุมทะเบียนพื้นที่ 77 จังหวัดตั้งแต่ต้น แต่แสดงพื้นที่/ช่วงเวลาที่ข้อมูลขาดตามจริง การมีชื่อจังหวัดในทะเบียนไม่เท่ากับมีข้อมูลทุกเรื่องครบจังหวัดนั้น

## ข้อมูลกลางที่ใช้ร่วมกัน

1. **บัญชีชุดข้อมูล:** เจ้าของข้อมูล, URL/resource, รุ่นและวันดึง, SHA-256, นิยามตัวชี้วัด, ระดับพื้นที่, ช่วงเวลา, หน่วย, ความถี่, สถานะความครบถ้วนและสิทธิ์ใช้/เผยแพร่ ผู้ใช้ต้องค้นเจอแม้ชุดข้อมูลยังใช้คำนวณไม่ได้

   [แผนที่แหล่งข้อมูล/API](accessible-data-map.md) เป็นบัญชีการค้นพบ/การเข้าถึงที่กว้างกว่าข้อมูลในเครื่อง ผล schema/คอลัมน์ที่อาจเชื่อมยังต้องผ่านเกณฑ์ด้านล่างก่อนเป็นข้อเท็จจริงกลาง
2. **รหัสอ้างอิง:** พื้นที่ พืช ช่วงเวลา และชนิดตัวชี้วัดพร้อมตารางเทียบรหัสที่ระบุรุ่นและผลตรวจ ห้ามใช้ชื่อที่สะกดเหมือนกันเป็น join key อัตโนมัติ ห้ามกระจายค่าระดับประเทศ/สถานี/กริดลงจังหวัดโดยไม่มีวิธีรองรับ
3. **ข้อเท็จจริงตามแหล่งต้นทาง:** เก็บแถวและ grain เดิมก่อน; แยก planned, observed, reported impact, risk estimate, price และ subtotal ให้ชัด ระบุ null, revision และที่มา ไม่บวกหรือเฉลี่ยข้ามสินค้า หน่วย ฤดู ตลาด หรือระดับพื้นที่
4. **ทะเบียนโครงการและผลลัพธ์:** หน่วยงานเจ้าของ, โครงการ/มาตรการ, พื้นที่เป้าหมาย, พืช/ปัญหา, ช่วงดำเนินงาน, งบ, เป้าหมาย, ตัวชี้วัด, ผลจริง, รุ่นข้อมูล และหลักฐาน ต้องสำรวจแหล่ง/สิทธิ์ก่อน เพราะข้อมูลโครงการที่มีตอนนี้ยังไม่ครอบคลุมทุกหน่วยงาน

ทุกชุดมีสถานะอย่างน้อย `ready`, `partial`, `needs_review`, `unavailable` พร้อมเหตุผลและเวลาปรับปรุง การแสดงผลหรือไฟล์ดาวน์โหลดต้องอ้างชุดต้นทางที่ใช้และสถานะสิทธิ์ ข้อมูลที่ระบุตัวบุคคลและข้อมูลสิทธิ์ pending เก็บในชั้นภายใน; ชั้นเผยแพร่ให้เฉพาะสถิติรวม/metadata ที่ผ่านการตรวจและได้รับสิทธิ์แล้ว ไม่เปลี่ยน pending เป็นอนุมัติเพราะเข้าถึง URL ได้

## ลำดับงานที่วัดผลได้

1. **บัญชีความครอบคลุม 77 จังหวัด:** ใช้แหล่งที่มีในเครื่องสร้างรายการ `source × area × period × metric` ระบุว่ามีค่าที่ใช้ได้หรือไม่, เหตุผลช่องว่าง, grain, unit, license, source revision และเวลาที่ตรวจ โดยแยกความหมายว่า “ไม่มีข้อมูล”, “ข้อมูลเก่า”, “รอตรวจ”, “ไม่อนุญาตเผยแพร่” ตรวจยอดกับ manifest ต้นทางก่อนใช้เป็นหลักฐานกลาง พื้นที่ระดับประเทศ/จุด/กริดต้องอยู่ grain เดิม ไม่เติมจังหวัดจำลอง
2. **ข้อเสนอเชิงพื้นที่พร้อมเหตุผล:** แสดงปัญหา/ช่องว่างที่ตรวจได้และข้อมูลประกอบ ไม่สร้างคะแนนรวมทุกความเสี่ยงหรือฟันธงความเสียหาย ตัวอย่างภัยน้ำใช้รายงาน DOAE เป็นหลักฐานพื้นที่ แล้วเพิ่มฝน/น้ำเมื่อจับช่วงเวลาและพื้นที่ได้จริง
3. **แผนเทียบผล:** คำนวณเฉพาะพืช พื้นที่ ฤดู รอบ และหน่วยที่ตรงกัน พร้อมตัวหารและ coverage; เมื่อไม่ตรงให้รายงานว่าเทียบไม่ได้ ข้อมูลแผนฤดูฝนปี 2569 กับผลที่มีปัจจุบันยังไม่มีจังหวัดตรงกัน
4. **ช่องว่างและผลของโครงการ:** เชื่อมทะเบียนโครงการเมื่อมีข้อมูลเจ้าของงานและผลจริงที่ตรวจแล้ว จึงตอบได้ว่าพื้นที่ใดถูกดูแล ซ้ำซ้อน หรือยังไม่มีมาตรการ และติดตามก่อน/หลังโดยไม่อ้างเหตุและผลเกินหลักฐาน
5. **การนำข้อมูลไปใช้ต่อ:** หลังสิทธิ์และคุณภาพผ่าน จัดชุดข้อมูลตามสัญญาเดียวกันให้หน่วยงานอื่นค้นผ่านเว็บ Next.js และดาวน์โหลดชุดที่อนุญาต พร้อมคำอธิบาย, version, วิธีอ้างอิง และรอบปรับปรุง เพิ่ม API เมื่อมีความจำเป็นตามผู้ใช้จริง ไม่อ้างว่าสัญญาในเครื่องเป็นบริการที่ deploy แล้ว

เริ่มส่งมอบเป็นช่วงจาก catalog ที่ตรวจแล้วสู่เว็บค้นหา/รายละเอียดได้ โดยไม่รอข้อมูลทั้งประเทศครบ จากนั้นเพิ่มหน้าพื้นที่ การสำรวจตัวชี้วัด และทะเบียนโครงการตามข้อมูลที่ผ่านเกณฑ์ เว็บต้องแสดงที่มา/หน่วย/เวลา/coverage/สิทธิ์และสถานะขาดข้อมูลจริง ทดสอบการกรองและค่าบนหน้าจอกับต้นทาง รวมทั้งมือถือและการใช้คีย์บอร์ด การมีหน้าเว็บหรือ build ผ่านไม่ใช่เกณฑ์ว่าแกนข้อมูลกลางเสร็จแล้ว
