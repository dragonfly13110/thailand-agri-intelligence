# บัญชีชั้นข้อมูล SSMap

ตรวจวันที่ 24 พฤศจิกายน 2569 จากเมนูของบัญชีที่ลงชื่อเข้าใช้ เทียบทุกชื่อกับบัญชีบริการแผนที่ แล้วทดลองขอข้อมูลจริงทีละตัวอย่าง

- เมนูหลักมี 126 ชั้นใน 6 กลุ่ม ตรงกับผลจาก GetLayerGroupOrTierList ทั้งชื่อและลำดับ เมนูขอบเขตอีก 5 รายการ รวม **131 รายการ**
- มีรหัสตรงกับทั้งบริการภาพแผนที่ WMS และบริการพิกัด WFS ของกรมส่งเสริมการเกษตร **129 จาก 131 รายการ** อีกสองรายการคือภาพน้ำท่วมซ้ำซากจาก GISTDA และผังแปลงดิจิทัลในเมนูขอบเขตซึ่งไม่มีรหัสชั้นในผลที่อ่านได้
- ทดลองขอพิกัดแบบ GeoJSON (ไฟล์พิกัดที่มีชื่อช่องข้อมูลกำกับ) สำเร็จ **20 ชั้น** จำนวน 1 รายการต่อชั้น และขอภาพ PNG สำเร็จ **8 ชั้น** จากกรมส่งเสริมการเกษตรโดยไม่ลงชื่อเข้าใช้ ภาพน้ำท่วมซ้ำซากของ GISTDA ขอได้เมื่อใช้กุญแจบริการ API ของ GISTDA
- บัญชีบริการกรมส่งเสริมการเกษตรมี WMS 618 ชื่อ และ WFS 617 ชื่อ รวมชื่อที่ไม่ได้อยู่ในเมนูบัญชีนี้ด้วย ผลตรวจด้านล่างจำกัดที่ 131 รายการของเมนูที่เทียบชื่อได้
- หลักฐานการเผยแพร่ต้องตรวจถึงระดับชุดข้อมูลก่อนนำขึ้นเว็บ กลุ่มผังแปลงรายแปลงและรายชื่อผู้ได้รับความช่วยเหลือตรวจเฉพาะชื่อในบัญชี

## ช่องทางที่ตรวจ

| ช่องทาง | ผล |
| --- | --- |
| SSMap หน้าแผนที่ | เลือกนครปฐม → พุทธมณฑลและเปิดเส้นทางน้ำได้ |
| ssmap-api.doae.go.th/api/GetLayerGroupOrTierList | รายชื่อ 126 ชั้น เมื่อร้องขอจากหน้าเว็บที่ลงชื่อเข้าใช้ได้ 200 ลองโดยไม่ลงชื่อเข้าใช้ได้ 403 |
| ssmap-api.doae.go.th/api/GetLayerGroupScopeGovernanceList | ขอบเขต 5 ชื่อ เมื่อร้องขอจากหน้าเว็บที่ลงชื่อเข้าใช้ได้ 200 ลองโดยไม่ลงชื่อเข้าใช้ได้ 403 |
| ssmap-api.doae.go.th/api/GetAllLayerList | ลองโดยไม่ลงชื่อเข้าใช้ได้ 403 |
| ssmap-api.doae.go.th/api/GetGeometryProvinceById และ GetGeometryDistrictById | เลือกนครปฐม → พุทธมณฑลแล้วคำขอสำเร็จ เส้นขอบขึ้นในหน้าเว็บ |
| ssmap-geo.doae.go.th/geoserver/ne/wms | WMS คือบริการส่งภาพแผนที่เหมือนแผ่นใสซ้อนบนแผนที่ ใช้ GetCapabilities ดูรายชื่อ และ GetMap ขอภาพ |
| ssmap-geo.doae.go.th/geoserver/ne/wfs | WFS คือบริการส่งพิกัดและช่องข้อมูล ให้เว็บวาดแผนที่เองได้ ใช้ GetCapabilities ดูรายชื่อ และ GetFeature ขอตัวอย่าง |
| api-gateway.gistda.or.th/api/2.0/resources/maps/flood-freq/wms | กรมส่งเสริมการเกษตรอ้างไปยัง GISTDA ทดสอบด้วยกุญแจบริการได้บัญชีชั้นและภาพ PNG |

แหล่งอ้างอิง [หน้า SSMap](https://ssmap.doae.go.th/maps) · [บริการ GISTDA](https://disaster.gistda.or.th/v2/services/open-api) · [บัญชีข้อมูล GISTDA](https://opendata.gistda.or.th/dataset/flood-disaster-data)

## ตัวอย่างที่ช่วยเลือกใช้ข้อมูล

- FarmerMap ปี 2567 ระดับจังหวัดและอำเภอคืนพิกัดพื้นที่จากการทดสอบ ในตัวอย่างระดับจังหวัดพบชื่อช่องครัวเรือน เพศ ช่วงอายุ พื้นที่เพาะปลูก ผลผลิต รายได้ และหนี้ ควรเทียบหน่วย นิยาม และวันตัดยอดกับเจ้าของชุดก่อนใช้ตัวเลข
- จุดรับซื้อข้าวคืนตำแหน่ง และมีช่องกำลังการผลิตกับข้อมูลเจ้าของในผลตอบกลับ หากนำมาทำแผนที่สาธารณะให้เลือกเฉพาะช่องที่จำเป็นและได้รับอนุญาต
- ตำแหน่งสถานีอากาศคืนพิกัด รหัส และข้อมูลติดตั้ง ในตัวอย่างช่องข้อมูลนี้ไม่พบค่าฝนหรืออุณหภูมิรายเวลา
- จุดความร้อน ต.ค. 2569 คืนตำแหน่ง มีช่องวัน เวลา ดาวเทียม ความเชื่อมั่น และกำลังการแผ่รังสีของไฟ ส่วนพื้นที่เสี่ยงอุทกภัย พ.ย. 2569 คืนขอบเขตและมีช่องประเภท ปี เดือน ใช้คนละความหมายกับขอบเขตพื้นที่น้ำท่วมที่ตรวจพบแล้ว
- ฝายรอบแรกไม่พบข้อมูลในกรอบทดสอบภาคกลาง พอขยายเป็นกรอบประเทศไทยได้พิกัด 1 จุด ภาพน้ำท่วมซ้ำซากของกรมพัฒนาที่ดินหมดเวลาเมื่อขอด้วยกรอบประเทศ แต่ได้ PNG เมื่อขอกรอบพุทธมณฑล
- ชั้นน้ำท่วมซ้ำซาก GISTDA เป็นคนละทางกับชั้นชื่อใกล้กันของกรมพัฒนาที่ดิน หน้าบัญชี GISTDA ระบุว่าไม่ระบุสัญญาอนุญาต จึงยังต้องยืนยันก่อนนำไปเผยแพร่ [บัญชีข้อมูล GISTDA](https://opendata.gistda.or.th/dataset/flood-disaster-data)
- หากจะเริ่มจากเส้นทางน้ำ มีชุด NAT_STREAM จากกรมทรัพยากรน้ำที่ระบุให้ใช้โดยให้เครดิต ยังไม่ได้เทียบว่าเป็นรุ่นเดียวกับ SSMap [ข้อมูลบน data.go.th](https://data.go.th/dataset/item_60fac91a-01c5-43da-b429-19e145a1ce7a)
