# ข้อมูลที่มีในโครงการ ณ 24 ตุลาคม 2569

โครงการมีข้อมูลจริงอยู่ในเครื่อง ทั้งสถิติพืช แผนเพาะปลูก ราคา น้ำ อากาศ ดาวเทียม วิสาหกิจ และข้อมูลอ้างอิงพื้นที่ เว็บเปิดดูตัวเลขได้บางชุดในโหมดเฉพาะเครื่อง ส่วนบัญชีแหล่งข้อมูลที่ค้นพบมีขนาดใหญ่กว่าข้อมูลที่ดาวน์โหลดและจัดรูปแล้วมาก

เอกสารนี้เป็นบัญชีจากไฟล์และฐานข้อมูลในเครื่อง ไม่ได้เรียก API ใหม่ในวันที่ 24 ตุลาคม ข้อมูลแต่ละชุดมีวันอ้างอิงต่างกัน จึงไม่ควรอ่านทั้งหมดเป็นสถานการณ์ปัจจุบัน สิทธิ์ตัวเลขต้นทางยัง `pending`; การมีข้อมูลหรือเปิดดูในเครื่องไม่ได้อนุญาตให้นำขึ้นเว็บสาธารณะ

ดู [เป้าหมายศูนย์ข้อมูล](../SYSTEM_DESIGN.md), [แผนเว็บ](../IMPLEMENTATION_PLAN.md), [คู่มือเว็บ](../web/README.md) และ [บัญชีความครอบคลุมเดิม](coverage-inventory.md) ประกอบ

## ข้อมูลที่ยังขาดหรือยังใช้สรุปไม่ได้

1. **ทะเบียนโครงการระดับรายการที่ยืนยันได้:** ยัง 0 รายการ ต้องมีพื้นที่เป้าหมาย เวลา วัตถุประสงค์ งบ เป้าหมาย หน่วยและผลจริง จึงจะประเมินความครอบคลุม/ซ้ำซ้อน/ช่องว่างมาตรการได้
2. **แผนเทียบผลที่พื้นที่และรอบตรงกัน:** ชุดที่มีอยู่ยังเทียบไม่ได้ ไม่สร้างร้อยละความสำเร็จจากคนละพื้นที่หรือคนละ grain
3. **การรวมผลผลิตข้ามเวลา:** ยังต้องพิสูจน์นิยามเดือน/รอบปลูกและ subtotal ไม่ถือว่า staging ผ่านแล้วแปลว่าบวกเป็นผลผลิตปีได้
4. **พื้นที่ตามยุคและพืช/สินค้า:** crosswalk ต้องตรวจชื่อสามระดับ รุ่นเขต รหัสพืช/พันธุ์ เกรดและหน่วย การตรงกันของชื่ออย่างเดียวไม่พอ
5. **น้ำ/อากาศ/ดาวเทียมที่ครอบคลุมพื้นที่จริง:** ข้อมูลสถานี/อ่าง/กริด/geometry ต้องมีวิธีเชื่อมพื้นที่ วันที่ หน่วยและคุณภาพที่พิสูจน์ได้ก่อนใช้ชี้เป้าจังหวัด
6. **ต้นทุนและรายได้ที่เทียบกันได้:** มีลิงก์/ข้อมูลประเทศบางส่วน แต่ยังไม่ใช่ต้นทุนหรือรายได้สุทธิของเกษตรกร/จังหวัด; ราคาประเทศคูณผลผลิตจังหวัดแทนไม่ได้
7. **สิทธิ์และข้อมูลส่วนบุคคล:** numerical observations และ exact-resource registry ยัง pending; ทะเบียน/คำขอ/รายชื่อและที่ตั้งบางชุดต้องอยู่ภายใน ห้ามย้าย raw ขึ้นเว็บเพียงเพราะโหลดมาแล้ว
8. **ข้อมูลล่าสุดและความครบ:** ปีที่มีและสถานะ API เป็นคนละเรื่องกับวันตรวจเอกสาร ต้องตรวจ refresh รายชุดพร้อม lineage ไม่อ้างว่า “สดทั้งประเทศ”

## หลักฐานและจุดที่แก้ความเข้าใจจากบัญชีเก่า

ตรวจไฟล์รายงานภายใน `current-data-inventory-2026-10-24.json` และ `current-access-map-inventory-2026-10-24.json` ร่วมกับ current run manifests, inventory และฐานแบบ read-only รายงานอยู่ภายใต้ `data/local/probes/` ซึ่งไม่เข้า Git เอกสารนี้เผยแพร่เฉพาะจำนวน ระดับข้อมูล ช่วงเวลาและข้อจำกัด ไม่คัดลอกค่าระเบียนจริง

- ตาราง production provincial ใน coverage เคยติดป้าย ธ.ค. 2566 แต่ source months/latest observations ครอบคลุม ม.ค. 2566–ก.พ. 2567; ไม่ใช้ป้ายเก่าสรุปยอดปี
- MODIS ใน coverage เก่าเคยระบุ MOD13Q1/28 ค่า/สองวัน แต่ข้อมูลปัจจุบันเป็น MOD13A1 (`modis-13A1-061`) 20 latest values วันที่ภาพ 30 ก.ย. 2569
- ยอดราคา raw 7,669, observations ที่มีค่า 7,657 และ latest 7,658 มีความหมายต่างกันตาม duplicate/conflict ข้างต้น
- P0/P1 พบ inventory หลายรุ่น 23/22 variants แต่ current run เลือก 21 resources ต่อกลุ่ม ไม่บวกสำเนา schema เก่า
- ความเสี่ยงขาดแคลนน้ำใน coverage ระบุ 2567–2568 แต่ selected inventory มี source year 2569; ข้อมูลจังหวัดรวมที่ติดป้าย 2566 มี source years 2554–2568 ความหมายช่วงเวลายังต้องตรวจต่อ
- Meteostat legacy 6 station-days กับ v2 3 station-days คนละช่วงและคนละ contract; ยังไม่ migrate จึงไม่รวมเป็นข้อมูลพร้อมใช้ 9 วันสถานี

เอกสารนี้เป็นภาพบัญชี ณ วันตรวจ ต้องปรับหลังมี ingestion/refresh หรือเปลี่ยนสิทธิ์จริง อ่าน [source license register](source-license-register.md), [data sharing](../SYSTEM_DESIGN.md) และ [weather v2](weather-v2.md) ก่อนนำข้อมูลไปใช้ต่อ
