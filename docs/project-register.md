# ทะเบียนโครงการเกษตรข้ามหน่วยงาน

อัปเดต 24 ต.ค. 2569: มีหน้าเว็บ `/projects` แสดงคำอธิบายจาก [ประกาศ DOAE 4 เม.ย. 2566](https://doaenews.doae.go.th/archives/17775) ที่ระบุนครปฐมเป็นเป้าหมายกิจกรรมพืชใช้น้ำน้อยแทนนาปรังในปีงบ2566/2567 เป็นหลักฐานแผน/รับสมัคร ยังไม่ยืนยันงบ เป้าหมายย่อย หรือผลจริงของนครปฐม/พุทธมณฑล จึงยังไม่เข้า verified project registry และไม่ใช้ชี้ว่ามีมาตรการครอบคลุมหรือมีผลสัมฤทธิ์ เก็บ metadata review ใน `data/local/probes/official-project-candidates-2026-10-24.json` ส่วนค่าศูนย์ด้านล่างยังหมายถึงสถานะการตรวจ ไม่ใช่การไม่มีโครงการจริง

สถานะ 23 ต.ค. 2569: **ยังไม่มีรายการโครงการที่ตรวจยืนยันพื้นที่เป้าหมายระดับโครงการได้** `audit_project_register.py` จึงคืน `registered_projects_count=0` และ `UNVERIFIED_NO_PROJECT_LEVEL_TARGETS` ไม่ใช้จำนวนศูนย์นี้สรุปว่าไม่มีโครงการจริง

การตรวจรอบนี้พบว่า `doae_15_01` เก็บจำนวนครัวเรือนและพื้นที่ของผู้เข้าร่วมตามจังหวัด เป็นสถิติการเข้าร่วม ไม่ใช่บัญชีพื้นที่เป้าหมายหรือสถานะดำเนินงานที่ผูกกับแต่ละโครงการ ส่วนรายการ MOAC/BAAC, ช่วยเหลือภัยพิบัติ และ LDD ที่เคยใส่ในโค้ดมีงบและรหัสจังหวัดคงที่โดยไม่มีหลักฐาน resource-level รองรับครบ จึงถอนออกจากทะเบียนที่ตรวจแล้ว ตัวเลขเดิมใน PBIP `offline-v12` และ `offline-v13` ห้ามใช้อ้างอิง

ข้อมูล raw/staging ของ DOAE ยังคงอยู่ใน `data/local/` สิทธิ์เผยแพร่ยัง `pending` อ่าน [แผนศูนย์ข้อมูลกลาง](../SYSTEM_DESIGN.md) และ [เช็กลิสต์ส่งต่องาน](../HANDOFF.md) ก่อนใช้

## หลักฐานที่ต้องมีต่อหนึ่งโครงการ

- รหัส/ชื่อโครงการและหน่วยงานเจ้าของจากเอกสารหรือ resource ที่ระบุรุ่น
- วัตถุประสงค์ กลุ่มเป้าหมาย พืช/ปัญหา และช่วงเวลาที่มีผล
- พื้นที่ **เป้าหมาย** ที่ระบุชัด แยกจากพื้นที่ที่มีผู้เข้าร่วมหรือมีรายงานผล
- งบ เป้าหมาย ผลจริง และสถานะ โดยเก็บ `null` เมื่อแหล่งไม่ระบุ
- URL/resource ID, วันที่เผยแพร่หรือรุ่น, SHA-256 และสิทธิ์ใช้/เผยแพร่

จนกว่าจะมีบัญชีโครงการที่ตรวจความครบถ้วนตามพื้นที่/เวลา การไม่พบชื่อโครงการในฐานนี้หมายถึง **ยังตรวจไม่ครบ** ไม่ใช่ช่องว่างมาตรการ

ตรวจซ้ำในเครื่อง:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/audit_project_register.py
```

ผลอยู่ที่ `data/local/probes/project-register-audit.json` และรูปแบบข้อมูลอยู่ใน [project.schema.json](../data_contracts/project.schema.json)
