## 2. ตรรกะการวิเคราะห์ความเชื่อมโยงเชิงพื้นที่และช่องว่าง (Gap & Redundancy Analysis)

โมดูล `tadih.project_register.analyze_spatial_project_coverage` ทำหน้าที่เปรียบเทียบระหว่าง:
1. **พื้นที่และพืชที่มีสัญญาณความเสี่ยง (Risk Signals):** เช่น พื้นที่เฝ้าระวังขาดแคลนน้ำ (`water-shortage-risk-area`), พื้นที่ประสบภัยแล้ง/น้ำท่วม (`disaster`), พื้นที่ความเหมาะสมต่ำ (`ldd_rice_zoning`)
2. **พื้นที่เป้าหมายของโครงการภาครัฐ (Project Interventions):**
   - **Covered Area:** พื้นที่เสี่ยงที่มีโครงการหรือมาตรการรองรับอยู่แล้ว
   - **Intervention Redundancy:** พื้นที่ที่มีโครงการซ้ำซ้อนกันมากกว่า 1 มาตรการในปัญหาเดียวกัน (เช่น ได้รับทั้งเงินเยียวยาภัยพิบัติและเงินชดเชยต้นทุน)
   - **Unaddressed Gap:** พื้นที่ประสบปัญหาจริงแต่ไม่มีโครงการหรือมาตรการช่วยเหลือใดลงไปถึง

## 3. กฎธรรมาภิบาลและการคุ้มครองข้อมูล (Data Governance)

1. ข้อมูลโครงการในชั้นนี้เป็น **สถิติสรุประดับโครงการและระดับจังหวัด (Aggregate Layer)**
2. ข้อมูลแปลงและประวัติเกษตรกรรายบุคคลที่มีใน `farmer.doae.go.th` และ `disaster.doae.go.th` ถูกคุ้มครองตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 และตาม [ร่าง Data Contract](doae-aggregate-data-contract-draft.md) ไม่มีการดึงข้อมูลระบุตัวบุคคลเข้าสู่ Git สาธารณะ
3. ทุกโครงการคงสถานะสิทธิ์ `pending` จนกว่าจะได้รับความเห็นชอบอย่างเป็นทางการ
