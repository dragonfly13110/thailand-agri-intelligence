# ตรวจรหัสพื้นที่ DOAE กับ DOPA snapshot ในเครื่อง

รัน `python -X utf8 scripts/audit_doae_geography.py` โดยอ่าน raw ที่ตรวจ SHA แล้วและ DOPA workbook วันที่ 1 ก.ย. 2566 จาก `data/local/` เท่านั้น ผลอยู่ที่ `data/local/doae-geography/inventory.json` และ `subdistrict-crosswalk.csv` ซึ่งถูก ignore และบีบอัดแบบ NTFS แล้ว ใช้พื้นที่ไฟล์ตรรกะ 26,891,311 bytes ไม่สร้างสำเนา raw หรือ staging รายแถวอีกชุด

ตรวจ 21 resources ที่มีคอลัมน์จังหวัด อำเภอ ตำบลตามรูปแบบที่ทบทวนไว้ รวม **2,757,305 source rows = 92,226 area signatures** นับรวม quarantine และ mock เพื่อให้ตรวจย้อนกลับได้ อีก 30 resources อยู่คนละ grain หรือรูปแบบและระบุเป็น skipped ใน inventory ไม่ถือว่าผ่าน crosswalk นี้ การรวม `source_record_count` ใน CSV เท่ากับ raw ของทุก resource ที่เลือก; SHA ของ output และยอดสถานะแต่ละ resource ตรวจซ้ำแล้ว

| ผลเทียบรหัสกับชื่อใน DOPA snapshot | จำนวนแถวต้นทาง |
|---|---:|
| รหัสและชื่อทั้งสามระดับตรงกันใน snapshot | 2,579,775 |
| รหัสกับชื่อขัดกัน | 947 |
| รหัสไม่อยู่ในชุด active ปี 2566 | 385 |
| รหัสอยู่ในชุด active แต่ชื่อจับคู่ไม่ได้ครบ | 3,366 |
| รหัสต้นทางผิดรูปแบบ | 1 (ข้อมูล mock) |
| ไม่มีรหัส, ตรวจได้เฉพาะชื่อ | 158,007 |
| ลำดับรหัสต้นทางไม่ครบ | 14,824 |

ข้อมูล `province_unified_data_10` ทั้ง 14,824 แถวอยู่ในกลุ่มลำดับรหัสไม่ครบ: มีแถวที่แสดงเฉพาะจังหวัด 1,320 และเฉพาะอำเภอ 13,504 จึงต้องตรวจ source grain ก่อนสร้างมิติหรือรวมยอด ไม่ใช่ตำบลที่ข้อมูลเสีย 14,824 แถว แหล่งอื่นยังมีชื่อ/รหัสบางระดับว่าง 172 แถว (149 แถวมีจังหวัดกับอำเภอ, 23 แถวว่างทุกระดับ) ต้องแยกตรวจเช่นกัน

ต้นทางปี 2567 ของพืชอายุสั้น/ยาวใช้รหัสแยกส่วน 2/2/2 หลัก สคริปต์ประกอบเป็น candidate 2/4/6 หลักเฉพาะเมื่อครบความยาวและตรงกับชื่อ/ลำดับพื้นที่ใน DOPA; เก็บรหัสต้นทางทุกช่องไว้ ไม่แทนที่ด้วย candidate ที่ขัดกัน ตัวอย่างในอำเภอกัลยาณิวัฒนา จ.เชียงใหม่ มีชื่อและรหัสตำบลที่สลับกันระหว่างต้นทางกับ DOPA snapshot จึงคง `code_name_conflict` ไว้ให้ตรวจรุ่นพื้นที่

**ข้อจำกัด:** DOPA ที่มีเป็น snapshot ปี 2566 โดย `valid_from` ยังไม่ทราบ ผล `code_and_names_match_snapshot` จึงยังไม่รับรองความถูกต้องในปีข้อมูลต้นทางหรือการเปลี่ยนเขต คอลัมน์ `rollup_eligible=False` ทุกแถว ไม่มีการรวมตัวเลข นำเข้า warehouse/Power Query หรือเผยแพร่ข้อมูลจากขั้นตอนนี้ สิทธิ์ทุกแหล่งยัง pending งานต่อคือยืนยัน temporal crosswalk, source grain ของชุดเอกภาพ และทบทวนแถวขัดกันก่อนเชื่อมข้อมูลในโมเดล
