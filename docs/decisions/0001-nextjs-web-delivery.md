# ADR-001: ใช้ Next.js เป็นช่องทางหลักของศูนย์ข้อมูลเกษตร

## สถานะและวันที่

Accepted ตามคำสั่งเจ้าของงาน 23 ตุลาคม 2569 (2026-10-23) หลังตัดสินใจเริ่มทำเว็บ catalog ในเครื่องแล้ว ดู [คู่มือเว็บ](../../web/README.md) ยังไม่มี deployment ที่ผ่านตรวจ

ปรับแนวทางข้อมูล 24 ตุลาคม 2569 ตาม [SYSTEM_DESIGN.md](../../SYSTEM_DESIGN.md): production อ่านฐานกลางที่ sync จากต้นทาง ไม่อ่าน snapshot/raw ใน checkout ระหว่าง request; รายละเอียดการส่งมอบเดิมใน ADR นี้เป็นประวัติของการตัดสินใจเลือก Next.js

## เหตุผล

เจ้าของงานยุติแนวทาง BI เพราะข้อจำกัดในการทำงาน และเลือก Next.js เพื่อให้พัฒนาเป็นเว็บ ศูนย์ข้อมูลยังมีเป้าหมายเดิม: รวมข้อมูลเกษตรทั้งประเทศให้ค้น ใช้หลักฐานร่วมกัน วางโครงการ และติดตามผลได้

## การตัดสินใจ

ใช้ Next.js + TypeScript + App Router เป็นชั้นใช้งานหลัก ใช้ Python/DuckDB และ contracts เดิมเป็นแกนข้อมูล เริ่มส่งมอบเว็บค้นหาข้อมูลจาก snapshot ที่ตรวจแล้ว ตาม [แผนงาน](../../IMPLEMENTATION_PLAN.md) และ [เป้าหมายศูนย์ข้อมูล](../../SYSTEM_DESIGN.md)

การตัดสินใจนี้แทนที่ข้อกำหนดส่งมอบผ่าน Power BI Import/Reports/App, PBIP/PBIR, DAX, Desktop/Service และกำหนดเวลาผูก Fabric Trial ในสเปก Thailand First v1.4 และแผนเก่าทั้งหมด ไม่ใช่การพัก BI หรือทำเว็บฝังรายงาน BI ข้อกำหนดคุณภาพข้อมูล สิทธิ์ coverage และหลักฐานยังคงใช้

ข้อกำหนดใหม่สำหรับแหล่งข้อมูลที่เว็บแสดงอยู่ใน [ADR-002](0002-source-backed-web-data.md): เว็บต้องใช้ source API/connector ฝั่ง server และห้ามใช้ raw/local files เป็นข้อมูล runtime

## ทางเลือกที่พิจารณา

- กลับไปทำ BI หลังข้อมูลพร้อม: ยุติตามคำสั่งเจ้าของงาน
- ฝัง BI ใน Next.js: ยังติดการพึ่งพาระบบเดิม จึงไม่ใช้
- เขียน ingestion/warehouse ใหม่ทั้งหมดใน JavaScript: ไม่มีเหตุจำเป็น ใช้แกน Python ที่มีต่อ

## ผลต่อการทำงาน

เกณฑ์รับงานเปลี่ยนเป็นความถูกต้องของข้อมูล/contract และ browser/build/deployment ที่ตรวจจริง ต้องรับผิดชอบเรื่องการเข้าถึง ความปลอดภัย ประสิทธิภาพ และการดูแลเว็บเอง การเปลี่ยนเครื่องมือไม่ได้แก้ข้อมูลขาดหรือสิทธิ์ pending อัตโนมัติ

เก็บ BI code/tests/snapshots เดิมเป็น legacy เพื่อรักษาหลักฐานและตรวจ dependencies ก่อนถอน ไม่ลบไฟล์หรือระบบออนไลน์ในรอบเปลี่ยนแผน สถานะและงานค้างใช้ [HANDOFF.md](../../HANDOFF.md) เป็นรายการกลาง
